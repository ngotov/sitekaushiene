# sitekaushiene

Главная страница Натальи Галюк-Каушене.

## Замена заглушек

Добавьте в репозиторий файлы с указанными именами — страница подхватит их автоматически без изменения кода:

- `media/about-video.mp4` — видео в блоке «Кто я»;
- `media/extra-photo.jpg` — дополнительный фотоблок;
- `media/reviews/review-01.mp4` — первый видеоотзыв;
- `media/reviews/review-02.mp4` — второй видеоотзыв;
- `media/reviews/review-03.mp4` — третий видеоотзыв.

Фото первого экрана уже находится по пути `public/images/foto_1_blok.png`.

## Пока не подключено

- реальные ссылки кнопок;
- отправка формы;
- контакты и социальные сети;
- две цены, отмеченные как `€...`.

После изменения ветки `main` GitHub Actions проверяет обязательные файлы и публикует страницу в GitHub Pages.
